01

Créer ton compte et démarrer

Le premier parcours est volontairement simple : tu crées ton identité, puis ton profil académique si tu es étudiant.

01

Inscription

Ouvre /inscription, choisis ton rôle et renseigne ton nom, ton numéro et ton mot de passe.

02

Numéro

Utilise le numéro associé à ton compte, dans le format accepté par la page de connexion.

03

Parcours

Pour un étudiant : université → composante → mention → niveau → filière si nécessaire.

04

Connexion

Retourne sur /connexion. Si le 2FA est activé, un deuxième écran demande le code.

!
Important pour les anciens comptes Les anciens comptes peuvent conserver leur format historique ; la page de connexion normalise le numéro avant la vérification.

03

Utiliser les documents

Les documents approuvés constituent la bibliothèque de ressources. Un document en attente de modération n'est pas encore public.

Pour chercher une ressource

  • Ouvre Documents depuis le menu.
  • Utilise la filière, la matière, le type de document ou le cercle pour affiner.
  • Ouvre le document voulu pour le consulter.
  • Un document approuvé peut être téléchargé selon les règles d'accès de son cercle.

Pour déposer un document

  • Ouvre la page de dépôt de documents.
  • Renseigne le titre, la matière, l'année et la filière.
  • Choisis éventuellement un cercle.
  • Ajoute le fichier autorisé puis envoie-le.
  • Le document passe ensuite par la modération avant d'être public.
A

Choisir

Un support PDF ou un autre format autorisé par la plateforme.

B

Décrire

Ajoute les informations pédagogiques pour que la ressource soit facilement retrouvée.

C

Modérer

Le document reste en attente tant qu'un administrateur ne l'a pas approuvé.

D

Partager

Une fois approuvé, il rejoint la bibliothèque publique ou le cercle concerné.

04

Apprendre avec les outils IA

Quiz IA et Tuteur IA sont deux usages différents : l'un mesure et entraîne tes connaissances, l'autre t'accompagne dans ton raisonnement.

Quiz IA

  • Choisis un quiz ou génère un quiz à partir d'un document disponible.
  • Réponds aux questions une par une.
  • Soumets la tentative pour obtenir le résultat.
  • Le tableau de bord peut ensuite afficher les quiz réellement terminés.

Tuteur IA

  • Pose une question liée à ton travail.
  • Donne suffisamment de contexte pour obtenir une réponse utile.
  • Utilise l'explication pour comprendre, puis vérifie avec ton cours.
  • Évite d'utiliser l'IA comme seule source pour une décision académique importante.
À retenir sur l'essai gratuitLe Quiz IA et le Tuteur IA sont disponibles pendant 14 jours pour un nouvel étudiant. Les autres fonctionnalités Premium restent accessibles pendant 60 jours. Un abonnement payant actif réouvre l'accès IA pendant sa période de validité.

05

Travailler dans un cercle d'étude

Les cercles sont des espaces collaboratifs. L'accès dépend du cercle, du statut du compte et, selon les cas, de l'abonnement.

01

Trouver

Ouvre Cercles et consulte les cercles disponibles.

02

Rejoindre

Si ton profil correspond, l'adhésion peut être directe ; sinon une demande peut être nécessaire selon le cercle.

03

Participer

Utilise le chat, les réactions, les réponses et les ressources partagées.

04

Partager

Un membre autorisé peut publier une pièce jointe ; les contrôles d'accès restent appliqués au serveur.

Messages

Écris un message court et clair. Les réponses et mentions permettent de poursuivre une discussion sans perdre le contexte.

Documents du cercle

Les documents liés à un cercle restent protégés : ils sont réservés aux personnes qui ont réellement accès à ce cercle.

Modération

Les actions de gestion sont réservées au créateur du cercle ou aux administrateurs selon les règles de permission.

06

Utiliser la classe virtuelle

Cette zone rassemble les cours, les inscriptions, les séances, les devoirs, la salle vidéo LiveKit et le tableau blanc collaboratif.

01

Cours

Ouvre Classe virtuelle et accède à un cours auquel tu es inscrit ou que tu gères.

02

Séance

Quand une séance est ouverte, rejoins la salle prévue pour le cours.

03

Travail

Utilise la vidéo, le chat de séance et, selon les permissions, le tableau blanc.

04

Devoir

Consulte l'énoncé et dépose ton rendu. Un étudiant ne peut récupérer que son propre rendu.

R
Permissions en temps réel Le tableau blanc revalide côté serveur la session et les permissions pendant l'utilisation. Une permission révoquée n'est donc pas censée rester active simplement parce qu'une ancienne connexion WebSocket est encore ouverte.
07

Gérer ton compte et ta sécurité

Le menu Sécurité centralise le profil, le mot de passe, l'email de récupération, le 2FA et les paramètres importants du compte.

ÉtudiantProfil académique, documents, quiz, tuteur, cercles et classe virtuelle.
Répétiteur / sponsorCompte sans parcours académique obligatoire, avec les fonctions accessibles à ce rôle.
AdministrateurAccès supplémentaire aux outils de modération et de gestion.

Comprendre ton essai et ton abonnement

La page Abonnement affiche deux compteurs : le Premium général et l'accès IA. Pendant l'essai, le compteur IA est limité à 14 jours ; le compteur Premium général va jusqu'à 60 jours.

Ouvrir la page Abonnement →

Mot de passe oublié

Depuis la connexion, sélectionne « Mot de passe oublié ? ». Le numéro sert à retrouver le compte et, si un email de récupération est disponible, un code temporaire est envoyé.

2FA

Quand la double authentification est active, la connexion se poursuit avec un code TOTP ou un code de secours.

Bon réflexe

Ne communique jamais ton mot de passe ni un code 2FA. Utilise le canal de récupération prévu si tu perds l'accès à ton compte.

08

En cas de problème

Avant de signaler un bug, suis ce mini diagnostic. Il couvre les problèmes d'accès les plus courants.

Je connais mon mot de passe mais la connexion est refusée.

Vérifie d'abord le numéro utilisé lors de l'inscription et respecte le format accepté par la page de connexion. Si le problème persiste, passe par « Mot de passe oublié » ou le contact.

Je ne vois pas un document que je viens de déposer.

Un nouveau document peut être en attente de modération. Tant qu'il n'est pas approuvé, il n'apparaît pas comme une ressource publique.

Je ne peux pas entrer dans un cercle.

Le cercle peut être actif mais l'adhésion dépend de ses règles. Vérifie aussi ton compte, ton profil académique et ton accès premium lorsque la fonctionnalité l'exige.

La classe virtuelle ou le tableau blanc ne fonctionne pas.

Vérifie que tu es réellement inscrit au cours ou que tu en es le professeur/admin, puis recharge la page. Les connexions temps réel sont contrôlées côté serveur.

Je n'ai plus accès à mon email de récupération.

Utilise le canal d'assistance indiqué sur la page de récupération du mot de passe. Ne partage pas ton mot de passe ni un code de sécurité dans un message public.

Le mode d'emploi évoluera avec les fonctionnalités du site. Pour les questions qui ne sont pas couvertes ici, consulte la FAQ ou la page Contact.
