01 Ouvre une application

Sur ton téléphone, ouvre une application d’authentification compatible TOTP. Tu peux utiliser, par exemple :

Google Authenticator Microsoft Authenticator Autre application TOTP

Choisis « Ajouter un compte » ou « Scanner un QR code ».

02 Scanne le QR code

Garde cette page ouverte et scanne le code depuis l’application sur ton téléphone.

Le QR code contient la clé secrète de ton compte. Ne le partage pas.

Je ne peux pas scanner le QR code

Dans l’application, choisis la configuration manuelle puis recopie cette clé.

{{ secret }}

Traite cette clé comme un mot de passe : toute personne qui la possède peut générer tes codes.

03 Vérifie et active

Entre les six chiffres affichés par l’application pour confirmer que la configuration fonctionne. Le code change régulièrement.

N’inclus ni espace ni tiret.
